## Highlighted Projects

### Graph Loot Engine
The <a href="https://github.com/garrettbovo/GraphLoot-Engine">Graph Loot Engine</a> is a C++ simulation engine that models traversal across a weighted graph of Points of Interest. It integrates Dijkstra's shortest-path algorithm with a probability-driven event system and supports both real-time operation and large-scale statistical analysis across more than 1,000,000 simulation runs. The engine is fully data-driven, loading graph topology and configuration from CSV files, and is built with a CMake-based build system, automated testing, and CI validation — the same engineering discipline expected of production simulation and modeling software.

### Collection System Simulation
A <a href="https://github.com/garrettbovo/Pokemon-Go-System-Simulation">C-based event-driven system</a> that models entity interactions, encounter generation, and inventory state transitions within a dynamic environment. The system integrates multiple core data structures, including a trie for efficient name-based lookup and a doubly linked list for managing tracked entities. Modular manager structures built on function pointers encapsulate menu handling, list operations, and trie functionality, keeping the system extensible without sacrificing determinism. Features manual memory management, pointer-based traversal, and file I/O pipelines for persistent state reporting.

### Student Registration System
A <a href="https://github.com/garrettbovo/Student-Registration-System-Simulation">C-based data management system</a> that models enrollment workflows with dynamic insertion, deletion, modification, and querying of structured records. Data integrity is enforced through validated input pipelines, and a trie-based index guarantees uniqueness of student identifiers. A doubly linked list supports efficient record management, including sorting, filtering, and in-place transformations. Like the collection system, it uses modular manager structures with function pointers and emphasizes manual memory management and persistent file output — patterns that translate directly to embedded and resource-constrained environments.
